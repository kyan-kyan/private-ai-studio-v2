03 Kaggleで実行

  1. 左のボタンで .ipynb をダウンロード。
  2. Kaggleを開く ↗ → New Notebook → File → Import Notebookからファイルを選択。
  3. Notebookの公開範囲を Private に設定。画像を含むため公開しないでください。
  4. Settingsで GPU T4 と Internet ON を設定し、Run All。
  5. 最後のセルに表示されるMP4を保存。下から選ぶと再生できます。

Kaggleへのログイン・GPU利用条件・空き枠が必要です。無料枠の範囲で利用してください。必要な本人確認やモデル利用条件の同意はご自身で行ってください。

エラーが出たら
  • GPUなし：AcceleratorをGPUに変更。
  • ダウンロード失敗：InternetをONに。401/403はモデルのアクセス権も確認。
  • メモリ不足：他のGPU処理を終了しセッションを再起動。
  • 依存関係エラー：出力の最初のエラーを確認。Notebookを再インポートして実行。
