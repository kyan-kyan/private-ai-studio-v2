03 Kaggleで実行（手動方式）

Kaggleを開く ↗

別タブで開きます。この画面を閉じずに切り替えると、準備した画像を保てます。

  1. 「画像入りNotebookを保存」ボタンで .ipynb をダウンロード。
  2. New Notebook → File → Import Notebook → Browse Filesで、ダウンロードした private-ai-studio.ipynb を選択。
  3. Notebookの公開範囲を Private に設定。画像を含むため公開しないでください。
  4. Settingsで GPU T4 と Internet ON を設定し、Run All。
  5. 最後のセルに表示されるMP4を保存。表示されない場合は右のOutputを更新し、/kaggle/working → private-ai-studio.mp4 → ⋮ → Download。下から選ぶと再生できます。
  6. 保存後はKaggle上部のセッションの ⋮ → Stop session でGPUを停止。

Kaggleへのログイン・GPU利用条件・空き枠が必要です。無料枠の範囲で利用してください。必要な本人確認やモデル利用条件の同意はご自身で行ってください。

スマホでメニューが見つからないとき

Chromeの右上 ⋮ から「PC版サイト」に切り替え、KaggleのFileやSettingsを探してください。ブラウザのダウンロード一覧から private-ai-studio.ipynb を確認できます。

実行前後の確認メモ

自分でチェックするメモです。Kaggleの生成状況とは連動しません。再読み込みすると消えます。

エラーが出たら
  • GPUなし：AcceleratorをGPUに変更。
  • ダウンロード失敗：InternetをONに。401/403はモデルのアクセス権も確認。
  • メモリ不足：他のGPU処理を終了しセッションを再起動。
  • 依存関係エラー：出力の最初のエラーを確認。Notebookを再インポートして実行。
